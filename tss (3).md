# Texivi Software Suite (TSS)

The TSS is a set of single-file Unix utilities following the Unkx philosophy and the TSP

> *"do one thing and do it well."*  

---

## Texivi Software Philosophy (TSP)

> *"Minimalism isn't about writing the fewest lines of code. It's about getting the most features out of the code you write."*

---

## Guidelines
### Every peice of software in the TSS has to follow these:

- **One File:** The everything is in one file.
- **Pack Each Line:** Avoid extra libraries that do not add functionality.
- **Use Standards:** Rely on standard system interfaces for portability.
- **Simple Builds:** Keep compilation and installation direct.
